# 👨‍💼 EmployeeHub – Employee Management System

A modern **Employee Management System** built with **React, Vite, Tailwind CSS, and Supabase**. EmployeeHub provides a clean dashboard to manage employee records, visualize analytics, and export data, all with a responsive interface and dark mode support.

## 🚀 Live Demo

🌐 **Live Website:** https://employee-hub-woad.vercel.app/

👨‍💻 **GitHub Repository:** https://github.com/rayyanahmadz/employeehub

---

## ✨ Features

* ➕ Add new employees
* ✏️ Update employee information
* 🗑️ Delete employee records
* 🔍 Real-time search
* 🏢 Filter employees by department
* ↕️ Sort by name and salary
* 📊 Interactive analytics dashboard
* 🥧 Salary distribution pie chart
* 📈 Employees by department chart
* 📤 Export employee data to CSV
* 🌙 Dark Mode
* 📱 Fully responsive design
* ✨ Smooth animations using Framer Motion
* ☁️ Cloud database powered by Supabase
* 📊 Power BI dashboard for business insights

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/rayyanahmadz/employeehub.git
```

Move into the project

```bash
cd employeehub
```

Install dependencies

```bash
npm install
```

Create a `.env` file and add:

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

Start the development server

```bash
npm run dev
```
